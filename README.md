## 条目取舍标准

**集团侧**只取成果与成绩，过滤党建、学习、会议类稿件。优先级：

1. 找矿成果（新增资源量、新发现矿产地、矿种突破、预查转普查/详查）
2. 项目承揽（探矿权、勘查、储量核实、生态修复、区外中标）
3. 工程节点（开工、验收、投产、试车）
4. 资质与荣誉（资质升级、获奖、入选示范）
5. 改革与人事（重组、任免、签约）

**自治区侧**优先带金额、面积、资源量、区块编号等硬数据的条目；纯通知类公告只在有实质节点时收录。不含集团自身动态。

**全国侧**优先全国首次、规模最大、填补空白、打破垄断性质的成果。
